# 儿童模式交互与排序调整

已按用户确认方案实施，仅 kotlin-tv 范围，红果接口、签名和重试策略保持原样。

- 搜索结果经独立 SeriesDisplayOrder 本地展示排序：同系列季数升序，明确搜索某季时该季优先。同页内整理，不额外请求跨页数据。
- 儿童首页复用搜索页 SearchResultCard；最近播放按更新时间倒排并过滤白名单，允许列表按中文名称及季数升序。列表按行复用，保留卡片焦点和滚动位置。
- 手机端新增允许列表与家长设置标签页；家长验证成功默认进入搜索，恢复本次连接的搜索词。允许列表在电视端整体排序后分页，增删不会改变电视儿童模式。
- TV 密码键盘最后一格为绘制的删除图标；遥控 DEL、FORWARD_DEL 和键盘 Backspace/Delete 共用删除操作，每次按下只删一位。
- 验证期间锁定数字、删除和提交；失败清空并恢复输入。取消后忽略旧回调，并撤销已取消验证产生的授权令牌。手机密码表单使用 disabled fieldset 锁定。
- 仅执行排序和交互的定向检查、手机脚本语法检查及 debug 编译，不运行全量测试或 CI。

验证覆盖：中文数字/阿拉伯季数、明确季数优先、名称与同名 ID 稳定排序、遥控删除及验证锁定、儿童卡片内容及排序。尚未进行 Android TV 真机遥控验收。
