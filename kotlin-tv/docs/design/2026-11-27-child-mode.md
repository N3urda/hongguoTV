# Android TV 儿童模式详细设计

日期：2026-11-27  
状态：待评审；本次仅形成设计，不代表已经实现。  
范围：本仓库 `kotlin-tv` Android TV 应用，以及由该应用提供的手机控制台网页。

## 1. 目标与项目约束

儿童模式开启后，只展示和播放家长明确加入白名单的作品；退出模式需要家长密码。家长可通过现有手机遥控控制台管理白名单，管理过程不解除电视上的播放限制。

严格遵守仓库 Agents.md：

1. 完全复用现有红果接口封装、签名和重试策略。不修改 ContentRepository、签名算法、设备注册或 PlayRetry 等行为。若实施中发现必须修改，先提出具体原因、范围和替代方案，取得用户确认后再做。
2. 仅阅读、修改 Android TV 范围。手机控制台是 kotlin-tv 内由电视提供的网页，不建设或修改其他手机客户端。
3. 优先新增独立文件，在现有页面和入口作小范围接入；不进行无关重构、全文件格式化、依赖升级，减少同步 main 的冲突。
4. 兼容 Android 6（API 23）、Android TV 6 和仅有方向键、确认键、返回键的遥控器。

## 2. 设计决策与默认范围

选择“儿童专属首页 + 本机作品白名单 + 家长验证”。仅隐藏非白名单播放按钮容易遗漏入口；多儿童档案、分龄、每日时长及云同步增加配置和实现成本，不纳入第一版。

以下是待评审的明确默认值，实施前可调整：

| 项目 | 第一版规则 |
| --- | --- |
| 授权粒度 | 整部作品，包含以后新增的集数 |
| 唯一标识 | 当前红果来源内的 Series.id；按字符串精确匹配 |
| 存储范围 | 本机应用，不依赖红果账号；换账号不清除 |
| 密码 | 6 位数字 PIN，首次设置输入两次 |
| 手机家长授权 | 每个浏览器独立授权；闲置 5 分钟或总时长 30 分钟过期 |
| 退出模式 | 每次退出重新输入 PIN，不复用浏览权限 |
| 密码错误限制 | 全设备共用计数；连续 5 次错误后锁定 60 秒 |
| 忘记密码 | 初次设置生成一次性恢复码；验证后设置新 PIN |
| 空白名单 | 可开启，展示空片单；绝不放开其他内容 |
| 弹幕 | 所有模式默认关闭；儿童模式始终强制关闭，退出后仍关闭，普通模式可手动开启 |
| 评论 | 儿童模式不展示，退出后恢复普通模式行为 |

产品边界：保护本应用内容，不提供系统级锁机。系统 Home、其他应用、卸载或清除应用数据不在普通应用可阻止的范围内。

## 3. 核心不变量

- 扫码连接只获得普通遥控权限，不能获得家长管理权限。
- 手机取得家长权限不改变电视的儿童模式开关。
- 普通模式下的白名单增删也必须通过家长验证，避免提前篡改片单。
- 每次启动、恢复和真正提交播放前，以电视端当前持久化策略为准。
- 手机传入的白名单标志、作品名称、封面、集数归属和播放地址均不能作为授权依据。
- 无法确认作品或剧集归属、策略读取异常时，拒绝播放，不回退到普通推荐。
- 弹幕全局默认关闭。儿童模式下的有效弹幕状态始终为关闭，不受保存偏好、手机命令、播放器恢复或换集影响；退出儿童模式也不自动开启。
- 修改成功必须表示数据已持久化成功；写入失败不能向手机或电视显示成功。

## 4. 状态与操作流程

### 4.1 状态

持久化状态为 UNCONFIGURED（未设密码）、NORMAL（已设置、普通模式）、CHILD（儿童模式）。另有运行时 RECOVERY_REQUIRED，表示已有配置损坏或版本无法读取，进入受限恢复页。

家长验证是独立的短期会话，不是第四种可放开播放的模式。电视、各手机会话分别管理。

### 4.2 首次配置与开启

设置 → 儿童模式 → 设置并确认 PIN → 展示恢复码并确认已保存 → 管理片单 → 开启。

开启时先暂停当前输出，持久化 CHILD，再使当前页面与任务失效，关闭普通推荐、预览和关联作品，进入儿童首页。不论原作品是否在白名单，第一版统一回首页，避免旧播放队列遗留。保存失败保持原模式，并明确提示未开启。

后续开启需要家长验证；重复开启保持 CHILD，不能形成切换回 NORMAL 的捷径。

### 4.3 退出、修改密码与恢复

退出入口 → 输入 PIN → 验证成功 → 持久化 NORMAL → 清理儿童页面 → 普通首页。取消或密码错误保留 CHILD。

修改 PIN 必须重新验证当前 PIN，输入新 PIN 两次；成功后撤销全部家长会话，但不改变儿童模式。

恢复码由密码学安全随机数生成，使用适合抄录的字符，提供至少 128 位随机熵；仅展示一次，数据库仅保存其摘要。忘记 PIN 时可在手机恢复页或电视的遥控字符键盘输入恢复码，验证成功后设置新 PIN、生成新恢复码、废止旧码并撤销全部家长会话。恢复密码不自动退出 CHILD。

忘记 PIN 且丢失恢复码时，不设置万能密码、日期密码或红果登录绕过入口。应用内无法恢复，应明确告知这一边界。存储严重损坏导致验证材料也无法读取时同样不自动解锁。

### 4.4 重启、升级与异常恢复

启动先加载儿童策略，再决定首屏，不短暂展示普通推荐。进程终止、断电、切换账号不解除 CHILD。手机连接及家长会话均不跨进程恢复。

使用带版本号的原子配置文件和系统备份副本恢复机制；配置解析失败进入 RECOVERY_REQUIRED。首次安装且没有任何配置记录可进入 UNCONFIGURED，已发现配置损坏不得当作首次安装。

## 5. 白名单模型与归属验证

建议模型：

```text
ChildModeConfig
  schemaVersion
  mode: NORMAL | CHILD
  policyRevision: Long
  pinCredential: algorithm, salt, iterations, digest
  recoveryCredential: digest
  failedAttempts, lockUntilEpochMillis
  entries: Map<String, AllowedSeries>

AllowedSeries
  seriesId: String
  title: String        // 展示快照，不参与授权
  cover: String        // 展示快照，不参与授权
  addedAt: Long
```

seriesId 不转浮点数或 JavaScript Number，不按剧名去重。当前业务使用单一红果来源；以后若引入其他来源，必须迁移成“来源 + 作品 ID”，不得直接混用 ID。

同名不同 ID 分别授权；改名而 ID 相同保持授权；第二季若有新作品 ID，必须单独添加。收藏、稍后看、历史记录不自动导入白名单。重复添加或删除已不存在项视为幂等成功。

添加时从电视已取得的有效作品卡片解析 ID 和展示数据。现有 PhoneControlCatalog 是有容量上限的临时卡片缓存，缓存过期时要求刷新，不能据手机上报的标题/封面直接创建授权项。持久白名单独立于此缓存，不能因其淘汰卡片而丢失。

播放验证顺序：

1. 取得电视持有的目标作品 ID，检查当前策略。
2. 使用原有 ContentRepository 详情/目录流程取得该作品的剧集目录。
3. 目标 episodeId 必须属于当前该作品已验证的目录；手机选集编号由电视映射，不能直接信任任意 episodeId。
4. 启动现有取流流程；所有签名、请求封装、清晰度和重试保持原样。
5. 在异步结果安装到播放器前，再核对当前作品、集 ID、请求代次和当前权限。

不要求每次播放都新增远程查询；当前有效、归属明确的详情目录可复用。详情或目录不完整时，只允许已经确认属于该作品的集数；后续集数等待现有目录加载确认后再播放。

## 6. 电视交互

儿童首页只包含“继续观看”“儿童片单”“家长入口”和“手机遥控连接”。继续观看与片单均来自白名单交集，不展示普通观看历史。

- 默认焦点在可播放卡片；空片单时落在手机连接入口。
- 作品详情只展示获准作品、简介、选集和播放，不展示关联作品、作者推荐、评论或弹幕。
- 返回键：播放器 → 儿童详情/首页 → 应用原有退出行为。离开应用不解除 CHILD。
- “家长入口”提供片单管理、退出模式、修改密码；管理弹窗结束后恢复原焦点。
- PIN 使用固定排列数字键盘，支持方向键与数字键，提供删除、确认和取消，字符以掩码显示。
- 所有功能无需触摸、长按或彩色功能键；高亮焦点清晰，文字与错误提示适应电视观看距离。
- 普通播放控制保留暂停、继续、快进、音量、选集与现有清晰度/倍速。
- 弹幕在所有模式下默认关闭；普通模式允许用户手动开启。开启儿童模式时立即停止弹幕调度并清空屏幕上的弹幕，取消在途弹幕加载，旧回调不得重新显示。儿童模式隐藏开启入口，电视端拒绝手机或其他入口的开启命令；换集、重播、前后台切换、进程重启后仍强制关闭。退出儿童模式仍保持关闭，不恢复进入前的开启状态。
- 首次应用该版本时，将旧版本保存的弹幕开启偏好一次性迁移为关闭；之后普通模式下用户主动修改的偏好按原机制保存，但进入儿童模式会将其重置为关闭。该迁移只改 TV 本地偏好，不改红果弹幕接口封装。
- 自动下一集限于获准作品；跨季、跨作品必须重新校验。第一版播完本作品返回儿童片单，不自动推荐新作品。
- 移除正在播放作品时，持久化成功后立即静音/停止、释放播放器和相关预加载，返回儿童首页。

电视家长管理第一版可查看和移除白名单；新增作品主要使用手机。普通模式作品详情提供“加入儿童片单”，操作仍需家长验证。

## 7. 手机控制台

继续使用电视现有 PhoneControlServer、PhoneConsole 与 PhoneControlPage，不增加独立移动应用或云服务。

普通连接在 CHILD 下展示白名单、获准作品详情和遥控。点击“家长管理”输入 PIN，成功后可以浏览原有搜索和个人片库并添加作品；电视界面不跳转到搜索结果。

搜索结果、作品详情和当前获准播放卡片展示“加入儿童片单 / 已加入”。加入只改片单，不自动播放。添加时显示“允许该作品全部集数，包括后续更新”。移除前确认；若正在电视播放，提示会停止播放。

手机页面依据服务端 policyRevision 刷新片单；客户端缓存失效不能影响服务端最终校验。多手机修改由电视串行执行，增删以单项操作合并，不能用整个列表覆盖他人刚做的修改。

### 7.1 权限矩阵

| 操作 | 普通模式普通连接 | CHILD 普通连接 | CHILD 已验证家长 |
| --- | --- | --- | --- |
| 遥控方向、暂停、快进 | 现有行为 | 可用，受电视页面约束 | 同左 |
| 点播 | 现有行为 | 仅白名单 | 仍仅白名单 |
| 普通搜索/推荐/收藏浏览 | 现有行为 | 不开放 | 可在手机浏览 |
| 搜索结果同步电视 sync=true | 现有行为 | 禁止 | 禁止 |
| 白名单增删 | 需家长验证 | 禁止 | 允许 |
| 账户登录、切换、收藏/预约修改 | 现有行为 | 禁止 | 第一版仍禁止，退出模式后处理 |
| 退出 CHILD | 不适用 | 需重新输入 PIN | 仍需重新输入 PIN |
| 修改 PIN | 需重新输入旧 PIN | 同左 | 同左 |

家长在 CHILD 下可浏览已登录账号现有收藏，但不能通过账号管理把电视切换到普通界面。原有手机 status 中账号信息、预约状态等字段在普通儿童连接下应省略。

### 7.2 建议新增命令

以下是电视本地控制协议设计，不是红果服务端接口：

| action | 参数 | 结果与权限 |
| --- | --- | --- |
| childStatus | 无 | enabled、revision、当前会话权限；不含密码材料 |
| parentUnlock | pin | 返回该手机独享短期管理令牌 |
| parentLock | parentToken | 撤销当前管理令牌 |
| childList | page | 白名单及 revision，儿童连接可读 |
| childAdd | parentToken、seriesId | 解析电视卡片后幂等添加 |
| childRemove | parentToken、seriesId | 幂等删除并处理当前播放 |
| childEnable | parentToken | 持久化开启，撤销已有管理会话 |
| childDisable | pin | 每次重新验证并退出，撤销会话 |
| childChangePin | oldPin、newPin、confirmPin | 更新凭据并撤销会话 |
| childRecover | recoveryCode、newPin、confirmPin | 更新凭据与恢复码，保持模式 |

复用现有错误消息格式，增加 code，例如 CHILD_NOT_ALLOWED、PARENT_AUTH_REQUIRED、PARENT_SESSION_EXPIRED、PIN_LOCKED、CATALOG_EXPIRED、POLICY_STORAGE_ERROR，并可返回 retryAfterSeconds。无需重构现有 HTTP 状态码策略。

普通浏览接口请求时校验家长权限，异步返回前再次校验。失效后拒绝返回全站结果，前端清除管理列表。封面接口也需要校验作品可见性，不能通过已缓存的卡片读到非白名单内容。

## 8. 密码、会话与持久化

密码保存为随机盐和经过迭代的派生值，不保存明文，也不使用简单单次 SHA 摘要。可使用 API 23 可用的 PBKDF2WithHmacSHA1，参数随记录保存；实施时在低端 Android 6 真机上校准迭代次数并记录结果，验证运算放在后台，避免主线程卡顿。比较摘要使用恒定时间比较。

恢复码校验、PIN 校验共用全设备错误计数和限制，不因换手机、重开网页或应用重启而清零。同一进程以单调时钟执行锁定；重启参考持久化截止时间，发现系统时钟异常时保守重新等待一个锁定周期。

家长令牌至少 128 位随机熵，只放手机页面内存，请求体携带，不进入 URL、日志、localStorage 或二维码。后台状态轮询不延长闲置时间，只有成功的家长主动操作才延长。令牌绑定当前控制服务器实例，不能用一个全局 isParent 标志替代。

当前手机控制台是局域网 HTTP。随机连接令牌与来源检查不能提供传输加密；本方案沿用现有局域网可信边界，不宣称抵御同网窃听。第一版不扩大为公网控制或远程访问服务。

配置采用独立的小型原子文件，包含模式、白名单、凭据、版本和修订号。写操作单队列串行化，写盘完成后发布不可变快照；失败保留旧快照。更严格的策略变更期间暂停相关播放提交，删除失败则保留原权限并提示失败。

配置不纳入现有书库导入/导出，普通书库恢复不能覆盖儿童策略；评估现有 Android 系统备份规则，对凭据和会话作独立处理，不能把未设密码的备份覆盖成解锁状态。会话仅驻内存。

## 9. 架构与现有代码接入

建议新增独立模块，命名在实现时可按项目风格微调：

| 模块 | 职责 |
| --- | --- |
| ChildModePolicy | 纯权限判断，作品/剧集约束和操作权限矩阵 |
| ChildModeStore | 原子配置读写、版本迁移、故障状态 |
| ParentAuthManager | 密码校验、恢复码、锁定、短期会话 |
| ChildModeController | 串行状态变更、修订号、撤销任务及页面通知 |
| ChildHomeScreen | 儿童片单、继续观看、空状态和焦点 |
| ParentGateDialog | TV 密码输入与错误提示 |
| ChildPhoneActions | 本地手机协议及权限适配 |

纯策略可放 kotlin-tv/core，不引入 Android 依赖；存储、时钟适配、UI 与播放生命周期放 kotlin-tv/app。红果请求仍交给现有封装。

已检查的接入点：

- MainActivity.openDetail：拒绝打开非白名单作品；在改变页面和释放当前播放之前检查。
- MainActivity.playEpisode：在队列快速跳转、取流、恢复或重试入口之前校验实际剧集归属。
- MainActivity 手机点播回调：先校验，再执行 saveProgress / releasePlayer，避免拒绝请求却中断合法播放。
- PhoneConsole.request：在搜索、推荐、登录、封面、片库及命令各分支前检查权限；仅在 MainActivity.phoneControl 检查不足以覆盖这些分支。
- PhoneConsole 的 showSearch 回调：CHILD 下禁止 sync=true，无论手机是否已获家长权限。
- PhoneControlCatalog：复用电视卡片解析和现有账号 scope；新增白名单状态，但不用其 80 张卡片缓存作为持久化白名单。
- PhoneControlPage：增加儿童片单与家长验证 UI，清除过期管理结果。
- 首页预览、PreparedSlot、queuedNext、自动下一季、MediaSession、生命周期恢复及异步取流结果：实施时逐一追踪实际调用链并补上最终校验。

上述只是接入设计，不意味着已验证全部播放路径。实施前须对 TV 内所有播放器创建、setMediaSource/setMediaItems、play 和队列晋升调用做一次完整入口审计。

## 10. 异步与并发处理

所有模式和白名单修改增加 policyRevision。播放任务记录作品 ID、集 ID、策略修订号及现有请求代次。

- 任务完成时若修订号变化，按当前快照重新判定；仍合法可继续，不合法则丢弃并关闭资源。
- 开启模式、删除当前作品、凭据异常进入受限页时，取消相关预加载、清除待播放队列，并使已经返回的旧异步回调失效。
- 缓存命中和下一集无缝切换也必须校验，不能以“已经取到地址”为授权依据。
- 改变账号不清除白名单，但仍使用现有账号 scope 丢弃旧账号请求结果。
- 管理页面授权到期时，未完成增删在真正提交前再次检查；过期则不落盘。
- 普通遥控的方向键不能代替家长验证；电视正在输入密码时，未验证手机的模拟按键不得向密码框注入数字或确认动作。

## 11. 兼容性和性能

不提高 minSdk，不因该功能升级播放器、网络库、构建工具或引入 WebView。电视 UI 使用现有 View 与焦点体系。

白名单权限判断使用内存 Map/Set，常规查询为 O(1)。封面沿用现有加载器，不把图片保存进策略文件。列表分批显示，密码计算和磁盘写入放后台。状态切换与播放器变更在主线程串行处理。

PIN 错误、网络错误、作品下架、白名单为空分别给出明确提示。网络不可用不影响读取本地片单、验证家长和退出模式；播放能否成功仍由现有播放能力决定，不承诺新增离线观看。

## 12. 验收与测试

### 12.1 权限和存储测试

- ID 精确匹配：同名不同作品、改名、新集、独立第二季、字符串长 ID。
- 家长会话隔离：手机 A 解锁不能解锁 B，过期、主动退出、断连、改 PIN 后令牌无效。
- 错误次数电视/手机共享，重连与重启不能立即绕过锁定；恢复码使用后失效。
- 原子保存失败不能报告成功；解析损坏进入受限页，版本迁移保留 CHILD。
- 重复增删幂等，多手机同时修改不会整表覆盖。

### 12.2 播放集成测试

- TV 点击、手机点播、历史续播、选集、自动下一集、跨季、MediaSession 恢复均遵守白名单。
- 伪造 seriesId/episodeId 组合拒绝播放；只发获准 ID 但使用其他剧集不成功。
- 开启时原播放立即停止，普通首页预览不残留声音或画面。
- 删除正在播放或正在加载的作品后，已缓存流、预加载、旧回调不能恢复播放。
- 修改无关白名单项后，当前仍获准的播放不无故中断。
- CHILD 下手机 sync=true 不能改变 TV 为普通搜索页。
- 家长可添加非白名单作品，但添加前即使已验证也不能直接播放它。

### 12.3 界面与真机验收

- Android 6 和 Android TV 6：纯遥控完成配置、开启、选剧、选集、退出和恢复码输入。
- Home、返回、进程终止、冷启动、断电重启、账号切换后状态正确。
- 儿童首页不闪现普通内容，评论不展示，空列表有明确焦点。
- 全新安装及旧版本升级迁移后弹幕默认关闭；普通模式可手动开启。开启儿童模式即清除已显示弹幕，加载中的弹幕结果不得重新显示。
- 儿童模式中通过电视、手机命令、旧偏好、换集、播放恢复或重启均不能开启弹幕；退出后仍关闭，只有普通模式下主动开启才可再次显示。
- 两部手机操作与会话超时后，电视和手机状态最终一致，服务端立即拒绝越权。
- 普通模式下原有播放、签名、重试、手机控制台和书库功能回归无变化。

测试重点是可观察行为及绕过路径，不只检查代码是否出现某个字符串。纯策略用单元测试，异步和存储用可控假时钟/故障注入，播放器与遥控流程用现有测试设施及 API 23 真机/模拟器验证。

## 13. 分阶段实施与交付

1. 权限基础：策略、存储、PIN、恢复码、会话、错误锁定与单元测试。
2. TV 限制：儿童首页、家长入口、启动恢复、所有播放通道校验。
3. 手机管理：独立家长会话、片单增删、搜索隔离、权限拒绝与状态同步。
4. 完整验证：异步撤销、故障恢复、多手机、API 23 遥控验收及普通模式回归。

每阶段保持仅修改 kotlin-tv；新增模块与接入补丁分清职责，不改红果网络封装。交付记录列出实际改动文件、测试结果及未覆盖设备，不以设计文档代替完成证据。

第一版必须同时具备 TV 最终权限校验和手机服务端鉴权，不能只发布 UI 隐藏。后续若新增播放入口或手机命令，必须将儿童权限验收纳入该功能测试。
