## 实际通过的路径

1. 主页加载真实推荐并播放；设置 → 账户 → 手机控制台打开二维码。
2. 控制接口真实搜索「拉黑遇真爱」，推送后实际播放；暂停、继续、快进、1.5 倍速、切第 3 集有效，读取到持续推进的播放进度。
3. 播放中搜索「总裁」第 1、2 页返回不同结果，电视原节目继续播放。
4. Chromium 390×844 页面加载模拟器实际提供的 HTML，经 ADB TCP 桥转发到控制服务，完成真实搜索和推送续播，无浏览器错误。此项不是实体手机同 Wi-Fi 验收。
5. 遥控器打开选集 → 跳转集数 → 清空并输入 1 →「播放此集」，一次确认后直接播放第 1 集，进度推进。检查截图可见正常视频画面。
6. 控制台开关 3 轮、每轮 20 次状态请求全部通过。返回后台待生命周期切换完成后旧端口拒绝连接；返回前台重新打开二维码，连接地址更换，新会话可用。
7. 本次结束时 Android crash 日志为空。未进行音频听感、长时间掉帧或 Android 8 实机验收。

## 内存观测与限制

在静态设置页关闭二维码后采样 `dumpsys meminfo`，单位 KiB：

| 阶段 | 关闭时 PSS | 开启时 PSS | 差值 |
| --- | ---: | ---: | ---: |
| 首次开启 | 119148 | 134060 | +14912 |
| 热态第 1 轮 | 125005 | 120152 | -4853 |
| 热态第 2 轮 | 118884 | 115313 | -3571 |
| 热态第 3 轮 | 114125 | 115109 | +984 |

首次开启采样增加约 **14.6 MiB**，超过预设 5 MiB 常驻增量目标；包含首次加载及二维码分配，未隔离 GC、换页影响，也不是峰值追踪。热态最后一轮约 **+0.96 MiB**，3 轮未观察到单调增长。负差值受回收和换页影响，不能解释为功能节省内存。上述样本不能证明满足 5 / 10 MiB 预算或所有低内存电视均无影响。

实现没有第二个播放器或全量封面缓存，限制并发、队列、响应体和片单缓存，后台关闭服务。仍需实体低内存电视比较开启前后 PSS、卡顿、视频解码稳定性，尤其首次打开二维码和长时间播放。
