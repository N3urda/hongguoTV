# 手机控制台改版验收

版本：0.13.2-debug.20261113，独立包名 com.hongguotv.nativeapp.debug。基于原功能分支继续修改，未混入本地多端实验代码。

## 交互变化

- 四个 tab：找剧、播放、片单、账户。页面移除方向遥控，播放按钮只放在播放 tab；推送作品后自动切到播放 tab。
- 预约列表只显示已上线，收藏、历史、本机记录在片单来源菜单中切换。相关作品中仍可预约未上线续作。
- 搜索联想停顿 350ms 后获取最多 8 条，过期响应丢弃，点联想直接搜索。
- 按标签找剧复用电视官方分类接口，支持类型、主题、设定、背景、推荐、受众、时间等服务端实际返回条件；切类型清空原标签，前后翻页使用游标。
- 未登录在手机账户页处理，不弹电视账户窗口。默认准备「打开红果 App 授权」链接；备选为短信验证码、二维码授权。账户切换自动清空旧片单。

## App 授权入口的证据和边界

官方 get_qrcode 返回 qrcode_index_url，路径为 https://reading.snssdk.com/reading_offline/novelread/page/scan-code.html 。官方 Android 包注册 dragon8662 scheme，DEX 中包含 dragon8662://webview?url= 的实际用法。官方授权页脚本要求 App 环境；直接用普通浏览器打开只提示扫码（https://lf-fe.fqnovelstatic.com/obj/novel-fanqie-fe/novel-dragon/feoffline/novelread/js/scan-code.2cbef601be91d78e81d5.js）。

服务端仅将 HTTPS、指定官方主机及路径、token 属于当前会话的地址包装为 App 链接。浏览器拿不到平台登录 Cookie；授权成功后电视核对账户并保存到既有加密存储。

在独立 Android TV API 36 模拟器安装官方 App，链接实际解析到 com.phoenix.read/com.dragon.read.push.AppSdkActivity，并进入官方 WebViewActivity。首次安装的隐私条款经用户明确授权后接受。过期链接展示官方过期页；新链接进入官方授权流程并提示设备需先登录。模拟器没有登录真实红果账户，因此 **已登录手机确认授权并同步电视的完整闭环尚未实测**。iOS、各手机浏览器的唤起兼容性待实机确认；被内置浏览器拦截时可用系统浏览器或验证码方式。

## 验证结果

- 核心 JVM 361 项，Android Robolectric 335 项，共 696 项通过；包含新增官方授权 URL 约束，以及 API 21/26 手机登录接口的冷却、轮询限频和 Cookie 不返回浏览器检查。
- 手机 Chromium 390×844 实际页面的 11 组场景通过：四 tab、无方向遥控、联想与文本安全、分页失败恢复、播放控制、标签组合与游标、App 链接与模拟授权确认、收藏/历史自动刷新、预约、短信冷却与清空输入、移动端布局、隐藏停止请求。分组包含多个断言，账号数据为合成 fixture。
- lintDebug / assembleDebug 通过。
- 通过 ADB TCP 桥连接模拟器真实 HTTP 服务：真实联想返回 8 条，真实分类返回 7 组标签，真实搜索与推送播放成功，实际 App 授权链接生成正常，浏览器错误为 0。此项不是手机同 Wi-Fi 验收。
- Android crash buffer 为空。未发送真实短信、未修改真实账户的收藏和预约。

## 内存

使用原 1024 MB Android TV 模拟器。新页面的渲染、标签和分页状态留在手机浏览器；没有新增电视播放器、WebView 或常驻服务，HTTP 仍最多两个处理线程。

完成真实联想、分类、播放和授权链接生成后单次样本 PSS 114268 KiB（正在播放），不是功能增量。回到静态设置页反复开关控制台 3 轮，每轮 20 次状态请求：

| 轮次 | 关闭 PSS KiB | 开启 PSS KiB |
| --- | ---: | ---: |
| 1 | 125222 | 115951 |
| 2 | 117473 | 116689 |
| 3 | 113687 | 111158 |

没有单调增长；负差值受 GC 与换页影响，不能说明功能降低内存。沿用前次首次开启约 +14.6 MiB 的限制说明，不宣称达到 5 / 10 MiB 预算。仍需低内存实体电视验证首次加载、长期播放和手机授权后的账户刷新。
