# 首页连续浏览与统一导航

## 行为

- 首页主操作改为“播放全集”，打开当前作品即按本机／账户观看进度正式播放。无观看进度时从首集开始。
- 从首页进入的正式播放，按返回直接显示当前作品的选集详情；再返回首页。播放器操作层显示时也遵守该路径。
- 后续作品元数据独立于视频准备、解码、缓冲和视频预加载。剩余不超过 5 部时开始补充下一批；批次结束或页码上限时保留已有卡片与播放位置，启动新批次。
- 右侧没有现成作品时保留“下一部”加载卡片，故障时显示重试。到边缘后继续右滑不会清空当前播放；多次右键合并为一次待完成切换，左移或切换分类会撤销这次待切换。
- 元数据失败或没有新作品时退避 15 秒，主动右键可重试。网络不可用时无法承诺立即提供新作品，但不会将右侧隐藏为一片空白，也不会用重复作品伪装新增。

## 视觉与生命周期

首页移除独有的蓝色玻璃面板，使用已有 `TvVisual`／`TvStyle` 的暗色面板、暖色强调与焦点样式；侧卡取消透视旋转。

`CatalogShell` 保存品牌栏、导航按钮、焦点和控件 ID。栏目切换和内容刷新只替换 body；进入详情或播放器才替换整页。点击已选栏目不重复创建页面。分类切换也保留首页组件和当前分类焦点。

## 回归覆盖

- 首页进入续播及返回选集，含已显示播放器操作层的情况。
- 批次续接保留当前作品、选集、播放位置与暂停状态。
- 视频准备失败仍能补充卡片；边缘等待不清空当前播放；快速右键合并。
- 导航身份与焦点保持、共享选中样式；已有账号历史和设置焦点回归。
