# 制作方作品与预约封面

分支基于 2026-11-11 获取的 `origin/main`：`614093e`。

## 界面

- 首页“相关剧集 / 预约”弹窗显示作品封面；详情页“全部季 / 相关作品”使用带封面的遥控卡片。
- 详情页显示“制作方：名称 · 查看作品”。没有资料时显示“暂无资料”；请求失败允许重试，播放仍可使用。
- 制作方作品弹窗保留当前剧集，并读取相关剧集中已核实同制作方的已上线作品。点击作品可进入详情，返回可回到原详情。
- 更多作品使用官方检索分页作为候选，再按元数据中的制作方编号核实。空的过滤结果不会提前截断上游分页。检索失败时保留已加载作品并提供重试。

## 来源与边界

制作方来自官方 `GET /reading/bookapi/multi-detail/v1/` 的 `author` 和 `media_id`。`media_id` 是内容供应方标识，不能用作社交账号 `user_id`。存在制作方编号时只按编号匹配；仅缺失编号时才精确匹配署名，不做同名账号推断。

目前没有验证可按制作方编号直接枚举全部作品的接口。更多作品候选来自官方网页 `/api/search/result`；UI 不将检索结果宣称为完整作品全集。2026-11-11 实测该检索接口返回 `search_rejected` / `Search is temporarily unavailable.`，因此当前已验证的是关联作品筛选与检索失败降级，不能宣称“全部作品”已经验收。

整系列预约按用户后续要求暂不实现，沿用单部待上线作品预约。
