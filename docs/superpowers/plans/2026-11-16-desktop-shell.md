# 桌面通用外壳原型

在当前分支新增 Compose Multiplatform Desktop JVM 客户端，共用 Windows/macOS 界面和现有 core。不改变 Android UI，不在原型中模拟真实播放。

设计：白色内容区 #FFFFFF、冷灰背景 #F3F5F8、深蓝文字 #17243B、辅助文字 #66748A、品牌红 #C83D50。系统无衬线字体；侧栏 196dp，内容最大化利用窗口，网格按宽度自适应。海报与剧名是视觉重点，避免技术信息占据主页面。

范围：发现、排行榜、会话收藏、搜索、详情、选集和明确的播放器占位。默认展示显式标识的演示内容，可切换真实接口；真实接口失败显示错误与重试，不偷偷替换为演示数据。演示内容为虚构，封面用排版占位，不冒充真实片源。

输入：鼠标点击、滚轮、Tab/Shift+Tab、Enter、Esc、Ctrl/Cmd+K。窗口最小 900×640，默认 1280×820。异步请求在后台执行，取消与请求代次保证旧响应不会覆盖新页面。

实施：建立模块；实现可测试的数据源/状态控制；建立桌面界面；编译测试、启动并检查截图；记录缺口和启动命令。播放器、账号登录、持久化收藏、安装包签名不属于本轮交付。

结果：模块、界面、异步状态与数据源完成；3 项桌面测试、10 项公共核心测试、381 项 JVM core 测试通过，Android 编译通过。macOS Temurin JDK 17 打包成功，启动截图及鼠标导航、详情、收藏、在线列表读取已验证。当前自动化无法成功向 Java 窗口发送键盘输入，因此键盘验收保留待完成；Windows CI 已配置但尚未远程执行。封面请求失败时显示占位，本轮未完成图片加载质量验收。
