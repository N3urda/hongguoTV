# 桌面真实播放接入

用户已要求继续将原型接成可实际观看的版本。本轮使用本机 mpv，通过官方 JSON IPC 控制独立原生视频窗口；Windows 共用控制层，采用命名管道，macOS 使用 Unix socket。界面负责选集、暂停、跳转、倍速、清晰度及续播。

复用 ContentRepository 与 RemoteVideo：解析真实片源并准备视频索引，通过仅绑定 127.0.0.1、随机路径的短生命周期 HTTP Range 服务供播放器读取。每个播放会话拥有独立播放器与数据源，切集和关闭会释放上一会话，不把媒体密钥或上游地址暴露到日志。

默认在线内容；本地文件持久化收藏与观看进度，启动恢复，失败显示可操作错误。演示模式仍可用于布局查看，但不模拟播放。

验证：HTTP Range 边界与实际输出、会话切换、数据往返测试；本机 mpv 真实片源播放、进度推进、暂停、seek、倍速和释放验收；重新打包启动。Windows 未实机验证时明确保留限制，不宣称四端播放器已全部交付。账户登录和云同步不属于本次播放器接入。

## 完成记录

新增 DesktopPlayback、MpvPlayer、PlaybackBridge、DesktopLibrary、DesktopArtwork 和 DesktopNetwork；默认在线，提供发现/排行/收藏/最近观看，集数按钮执行真实播放。视频显示在独立原生窗口，外壳底部控制播放。

定位到系统代理使部分上游 TLS 握手超过 5 秒，直连约 0.2 秒；内容请求默认直连，保留显式系统代理选项。core 新增 preparePlaybackSession，在短模型时限前完成匿名会话准备，新增注册复用测试，Android 原路径不变。

7 项桌面、382 项 JVM core、10 项公共核心测试通过；Android 编译通过。真实片源解码、暂停、seek、倍速、自动下一集、持久化续播验收通过；macOS 应用包重新生成，界面实际播放至约 27 秒后暂停供用户查看。Windows 和长时间播放仍未实机验收，未推送或发布。
