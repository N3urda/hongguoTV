# 桌面端与电视端功能对齐

分支：`codex/kmp-shared-core-plan`。在共用 JVM core / KMP shared-core 上补齐桌面业务入口，Android TV 的现有界面和播放实现保持各自平台适配。

## 本次落地

| 电视端能力 | 桌面实现 | 验证范围 |
|---|---|---|
| 扫码、短信登录（含国际区号） | 复用 WebLogin / PhoneLogin；扫码轮询、过期重取、短信冷却、更换号码 | 二维码实际获取；协议单测；真实账号确认待用户操作 |
| 记住登录、退出账号 | 用户勾选后 macOS Keychain / Windows CurrentUser DPAPI；无明文降级 | macOS 独立虚构凭据往返；恢复/退出单测；Windows 待实机 |
| 云收藏、云历史、预约 | 登录后显示云收藏、本机/云历史合并；写入后回读确认；预约列表 | 网关替身测试及原 core 协议测试；真实账号读写待验收 |
| 跨端续播、进度同步 | 选择本机/云端较新进度；周期上传，结束/切集额外上传 | 本机播放/续播已实测；云端上传待真实账号 |
| 分类、题材、榜单 | 真人/漫剧/AI 分类与题材、四类榜单、分页 | 编译、core 解析测试、macOS UI |
| 搜索建议、推荐 | 防抖搜索建议；匿名/账号推荐流，顺序翻页 | 共用 core 测试；账号个性化待验收 |
| 详情、制作方、相关季数 | 详情先展示；相关信息异步加载；查看制作方作品、预约待上线季 | 编译与公共接口接入；制作方作品支持翻页并保留独立列表来源 |
| 评论、弹幕 | 当前选集评论/更多评论；按播放时间加载弹幕，在 mpv OSD 显示 | core 解析及文本安全测试；弹幕采用定时文字显示，非 TV 滚动排版 |
| 播放体验 | 清晰度/倍速/自动连播；保守匹配下一季；画面比例、旋转、分钟/集数定时关闭 | 真实 mpv 播放回归；公共计时和季数规则测试 |
| 偏好保存 | 清晰度、倍速、自动连播、画面比例、弹幕开关 | 读写重启测试；保留原收藏/历史 |

## 平台差异与未验收项

- 桌面使用独立 mpv 窗口；TV 使用 Media3/原生解码回退。APK 更新、遥控器焦点和手机遥控控制台不直接移植到桌面；桌面有鼠标键盘与本机播放器控制。
- 桌面不包含 TV 解码经验库、NAS 中继、内嵌视频或自动更新；当前不宣称所有 TV 工具逐项完全等价。
- 桌面支持浅色/深色外观并保存偏好；电视大屏布局、滚动弹幕排版属于外围 UI 差异。
- Windows 构建/命名管道/DPAPI 的真实运行、真实账号短信/扫码成功后的云同步、长期压力运行尚需对应环境验收。不能用 mock 测试替代这些验收。
- 短信仅由用户点击发送，不自动请求验证码；不修改用户真实云收藏来制造测试数据。
- 凭据从不写入日志或普通 JSON。本机 library.json 继续保留收藏、历史及非敏感偏好。

## 验证命令

```sh
./kotlin-tv/gradlew -p kotlin-tv :app-desktop:test :core:test :app:compileDebugKotlin :app-desktop:createDistributable
./kotlin-tv/gradlew -p kotlin-tv :app-desktop:run --args=--smoke-controller
```

mpv 画面参数与文字命令依据 [官方稳定版手册](https://mpv.io/manual/stable/)。

## 本轮结果

13 项桌面测试 + 382 项 core 测试 + 10 项 shared-core 测试全部通过；Android Kotlin 编译和 macOS 打包通过。真实片源解码、暂停、seek、倍速、比例/旋转参数、自动下一集、持久化续播和按集定时关闭通过。发现并修复画面参数早于视频轨道就绪的启动时序问题。未使用真实账号执行收藏/预约写入。

## 第二轮功能与可用性完善

- 制作方作品支持分页；全局搜索从收藏/历史/推荐页发起时都执行在线搜索。
- 从详情返回保留页码、列表和滚动位置；迟到详情不再覆盖已经返回的页面。
- 未上线预约展示上线说明，不请求播放资源。资料库刷新同时刷新云端记录。
- 详情每 40 集分组，支持输入集数播放；卡片和详情显示已看集数与分钟/秒续播位置。
- 新增稍后看（本机最多 100 条）；导入/导出与 TV 相同格式的收藏、历史、稍后看备份。导入保留较新本机进度，不写云端、不导入登录态、不替换播放设置。电视端搜索记录、隐藏列表等不在桌面导入范围。
- 深色/浅色外观持久化；小窗口侧栏可滚动，账号面板限制高度；播放操作与进度分行，增加全屏、静音按钮。
- 云上传进行中合并后续进度并继续发送最新值；切集评论不沿用上一集分页游标。
- 验证：19 桌面 + 399 core + 10 shared-core，共 428 项测试通过；Android Kotlin 编译、macOS 打包通过。真实 v5 片源播放、暂停、seek、倍速、自动下一集、续播、按集定时停止回归通过。macOS UI 实测深色外观、81–96 集分组及备份入口。
- 尚未把 Windows 实机、真实账号云读写、NAS 中继、桌面自动更新、内嵌播放器和 TV 滚动弹幕等标记为完成；上述平台差异和验收边界仍适用。
