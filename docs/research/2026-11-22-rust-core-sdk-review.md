# Rust core 与 OpenHongGuo 能力取舍

对照 OpenHongGuo v0.4.0（`cd27b9e`）、本项目 `codex/rust-desktop` 的工作区和 `main` 的 Kotlin 实现。以桌面、手机、电视客户端真实使用的入口作为取舍依据。

| 能力 | 对照结论 | 决定 |
|---|---|---|
| 播放模型、选档、Range、解密和恢复 | 上游提供媒体模型和 HLS/DASH 信息。本项目已有桌面正片与试看分流、MP4 流读取、分段解密和备用源恢复。 | 保留现有播放链路。排除整 SDK 替换以及新增 HLS/DASH、下载、外部播放器托管。 |
| 匿名设备、网络错误、重试 | 上游将设备存储、传输和错误分开。本项目已有可注入的档案存储、桌面平台凭据库以及分层取流错误。 | 采用档案复用和结构化错误。放弃远程签名、开放任意请求地址、按限流或拒绝自动重试换设备。 |
| 找剧、搜索、短剧榜 | 已有多条件找剧、官网搜索、联想、短剧排行榜、随心看。桌面展示层已经按剧集 ID 去重。 | 由 core 验证找剧游标的筛选条件、匿名身份与上游会话。区分真实搜索空结果与不兼容响应。排除独立书城分类、活动榜和自动遍历器。 |
| 弹幕与公开评论 | 上游用分集时长及上游游标推进时间段。本项目已经从播放器拿到时长，并验证弹幕所属分集。 | 由 core 保存续页所需的剧集、分集、时长、时间段和匿名设备。空段可以继续，明确结束时终止，拖动后从新位置开始。客户端只接收本地续页 ID。 |
| 剧集详情、相关推荐和多季 | 本项目已使用官网详情和分集列表，支持相关作品和唯一下一季。上游还提供批量详情和合集查询。 | 保留现有分季与作品匹配规则。排除面向任意场景的详情批量 API 和泛化合集接口。 |
| 预约、新剧、观看记录和收藏 | 本项目已有账户读写、预约确认、观看进度同步与新剧榜。上游的上新日历属于匿名目录。 | 保留单剧预约和写后确认，排除新增独立上新日历及整系列预约。 |
| 演员主页、角色作品、制作方 | 上游演员入口需要演员榜中的账号 ID。项目已有 Kotlin 制作方作品功能，使用内容供应方 ID。 | 维持现有制作方产品能力。演员榜、演员主页和参演作品移出公共 core 范围，制作方身份按独立数据语义处理。 |
| 绑定与部署 | 上游提供多个语言绑定和 CLI。桌面直接依赖 Rust，Android 手机和 TV 通过 JNI 复用续播、选档、Range、找剧和弹幕规则。 | 保留平台原生网络与账号入口。排除 AAR、WASM、Go 运行时及跨平台签名服务。 |
| 接口契约与诊断 | 上游用开关和样本检查真实接口。日常 CI 已覆盖 Rust 全 feature。 | 周检扩展到公开搜索联想、榜单和分集评论。添加手工匿名契约探测，检查播放模型、多条件找剧续页、相关作品和弹幕续页。媒体探测分别输出取流、打开媒体和 Range 读取耗时。 |

## 验收口径

- 公开目录探测和匿名注册源探测调用应用的 Rust 代码。匿名探测使用已在官网核对过的剧集、分集和实际时长，自动周检仅运行公开目录。
- 弹幕核心测试覆盖空段、结束信号、错误分集和拖动位置。桌面测试用模拟播放器事件走通连续读取、过期续页恢复、结束和拖动重启。
- 真实账户的预约、收藏、进度写入以及系统凭据库的安装版验证，分别属于账户与平台验收。播放器首帧和拖动体验属于桌面或设备验收。

探测命令与输入见 [Rust core 验证说明](../../rust-core/README.md#验证)。
