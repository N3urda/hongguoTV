# 手机控制台（Issue #43）

## 使用

在电视「找剧 → 手机控制台」或「设置 → 账户 → 手机控制台」打开二维码，用同一可互通局域网内的手机浏览器扫码。关闭二维码窗口后连接继续有效，可继续在电视播放。

- 找剧：搜索、上一页/下一页、在电视播放并续播。默认只更新手机；勾选「搜索结果同时显示到电视」后，电视会保存当前进度并退出播放，显示同页结果。
- 播放控制：暂停/继续、上一集/下一集、前后 15 秒、指定集数、倍速、清晰度。清晰度复用电视现有选流策略，不保证内容具备对应清晰度。
- 方向遥控：上下左右、确定、返回；二维码、账户、选集弹窗优先接收按键。首页浏览可用方向遥控，专用播放按钮适用于正式剧集播放页。
- 我的：账户收藏、账户历史、本机收藏、本机历史、稍后看。账户历史播放携带云端续播位置，本机记录保持独立。
- 账户收藏：加入收藏、在账户收藏页移除；沿用已有读前核对和写后确认逻辑。
- 账户预约：已上线/未上线分开显示。未上线禁止播放；从相关作品中点击一次即可预约待上线作品，省去二次操作菜单；自动核对后显示「已预约」，暂未同步时显示「已提交」。
- 账户管理：手机触发电视账户窗口，继续使用电视既有登录流程；浏览器不接收平台 Cookie 或令牌。

当前上游预约分页协议仍未验证，每类只呈现当前读取的最近 20 部。新增预约提交后自动读取账户列表，未确认时延迟 750 毫秒再核对一次；只重试读取，不重复提交预约。没有持续后台轮询，也不要求用户手动刷新；只有列表确认后才标记「已预约」。不会把本机稍后看当作平台预约。

电视离开前台、销毁 Activity、切换网络或主动断开时关闭当前会话。返回前台会在本次启用状态下重建会话并更换地址令牌；需要重新扫码。完全重启应用后需再次打开控制台。没有常驻后台 Service、唤醒锁或后台播放。

## 低内存约束

- 只有用户首次打开控制台后才创建监听服务。
- 一个监听线程；最多两个 HTTP 处理线程、两个排队连接，满载直接关闭多余连接。
- 每个会话最多一个搜索/相关作品请求在途；非状态操作最多每秒 12 次。控制请求独立于电视目录请求，不调用电视全局搜索状态，除非用户勾选同步。
- HTTP 头合计最多 8 KiB、请求体最多 4 KiB；读取超时 1.5 秒、完整请求读取期限 4 秒。
- 元数据 HTTP 响应限制为 1 MiB（包括未知长度流）；连接超时 5 秒、读取 8 秒、单次调用 12 秒。使用独立请求取消范围，停止服务不会取消电视播放请求。
- 浏览器 JSON 响应最多 256 KiB。每页本机/账户列表 20 条、搜索/相关作品输出最多 40 条；可操作卡片最多保留 80 条，只存编号、短标题和摘要，不存封面或完整详情。超过保留范围的旧卡片要求重新读取。
- 手机页面没有封面、外部框架、WebView、视频、额外视频缓冲或播放器。
- 播放状态每 3 秒读取本地快照；不为轮询调用上游账户接口；页面隐藏后停止轮询。账户列表异步刷新期间每 1.5 秒读取本地加载状态，完成后停止。
- 会话关闭后关闭全部客户端套接字，停止请求线程、取消元数据请求并释放连接池；过期主线程回调不能改变电视状态。

这些是实现上限，不是 Android 内存实测结果。验收预算仍为：无手机连接时新增 PSS ≤5 MiB，单手机常规操作稳态新增 PSS ≤10 MiB；真机验证后才可判定是否达标。

## 连接边界

每次会话使用随机 192 位地址令牌，只绑定电视选定的局域网 IPv4 地址。请求要求精确 Host，写接口要求同源 Origin 和自定义请求头；拒绝跨站请求、重复请求头和分块上传。网页设置 CSP、禁止嵌入、禁止缓存和 referrer，远端标题仅以 textContent 渲染。

账户切换使旧卡片失效，收藏/预约/播放指令携带读取时的账户代次，避免旧页面作用于新账户。手机与电视之间仍是局域网 HTTP，二维码等同本次控制权限，不应分享；应用退出或「断开所有手机」即可撤销。

## 测试与复现

```sh
cd kotlin-tv
./gradlew :core:test :app:testDebugUnitTest :app:lintDebug :app:assembleDebug --console=plain
```

浏览器交互测试需要 Node.js、Playwright 和 Chromium：

```sh
node scripts/test-phone-control-ui.cjs
```

浏览器测试运行本地模拟数据，不连接真实账户、不提交真实收藏或预约。截图写入 `outputs/phone-control/mobile.png`。服务套接字、鉴权、请求上限、并发上限和关闭由 `PhoneControlServerTest` 验证；API 21/26 上的账户隔离、分页、有限缓存和会话生命周期由 Robolectric 验证。

真机验收建议使用同一视频、同一清晰度和相同预热时间，对比控制台关闭、打开未连接、连接闲置、连续搜索/翻页/切剧、退出重入五组；每组运行至少 10 分钟，重复连接断开 30 次。记录 `adb shell dumpsys meminfo com.hongguotv.nativeapp` 的 TOTAL PSS、Native/Java Heap，结合线程数、GC 和播放掉帧/卡顿比较。特别覆盖 1–2 GB 内存电视、Wi-Fi 断线重连和双手机同时操作。桌面 JVM/Robolectric 数据不能替代电视 PSS 或解码器内存测量。
