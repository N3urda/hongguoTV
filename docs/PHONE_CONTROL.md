# 手机控制台（Issue #43）

## 使用

在电视「搜索 → 手机控制台」或「设置 → 账户 → 手机控制台」打开二维码，用同一可互通局域网内的手机浏览器扫码。关闭二维码窗口后连接继续有效，可继续在电视播放。

- 找剧：搜索、上一页/下一页、在电视播放并续播；相关作品可返回原列表，失败页可原地重试。搜索和筛选只更新手机，点击「电视播放」才切换电视内容。手机推送后，电视返回会打开当前剧集详情与选集，保留当前集数。
- 播放控制：暂停/继续、上一集/下一集、前后 15 秒、指定集数、倍速、清晰度。清晰度复用电视现有选流策略，不保证内容具备对应清晰度。
- 页面分为找剧、播放、片单、账户四个 tab；手机页面移除方向遥控。播放控制只在播放 tab 显示。
- 片单：收藏、历史、预约、稍后看四个二级标签。收藏和历史合并本机与当前账户记录，并按剧集去重；历史按最近观看排序，续播采用较新的本机或账户进度。未登录仍显示本机收藏和历史。预约继续显示已上线作品。
- 筛选：所有分组默认展开，选项换行成块；每组初始最多 8 项（含“全部”），点击“展示更多”每次增加 8 项，全部显示后按钮消失。刷新列表保留展开状态和已显示项数；选中的条件始终可见。
- 账户收藏：加入收藏、在账户收藏页移除；点击加入后直接提交并自动核对；取消保留一次确认。按钮和当前列表自动更新，不再要求操作后手动刷新。
- 账户预约列表只显示已上线作品。未上线禁止播放；从相关作品中点击一次即可预约待上线作品，省去二次操作菜单；自动核对后显示「已预约」，暂未同步时显示「已提交」。
- 手机登录：账户 tab 自动准备「打开红果 App 授权」链接，手机红果需已登录；确认后返回浏览器自动同步电视。备选为手机验证码登录或二维码授权，无需回电视输入。浏览器不接收平台 Cookie 或登录凭据。
- 搜索联想：输入停顿 350ms 请求最多 8 条，过期响应不覆盖新输入。标签筛选复用电视端类型、主题、设定等官方条件；更换类型清空旧标签，分页传递服务端游标。

当前上游预约分页协议仍未验证，每类只呈现当前读取的最近 20 部。新增预约提交后自动读取账户列表，未确认时延迟 750 毫秒再核对一次；只重试读取，不重复提交预约。没有持续后台轮询，也不要求用户手动刷新；只有列表确认后才标记「已预约」。不会把本机稍后看当作平台预约。

电视离开前台、销毁 Activity、切换网络或主动断开时关闭当前会话。返回前台会在本次启用状态下重建会话并更换地址令牌；需要重新扫码。完全重启应用后需再次打开控制台。没有常驻后台 Service、唤醒锁或后台播放。

## 低内存约束

- 只有用户首次打开控制台后才创建监听服务。
- 一个监听线程；最多两个 HTTP 处理线程、两个排队连接，满载直接关闭多余连接。
- 每个会话最多一个搜索/筛选/相关作品请求，以及一个联想请求在途；共用原有两个处理线程。非状态操作最多每秒 12 次，控制台浏览独立于电视目录状态。
- HTTP 头合计最多 8 KiB、请求体最多 4 KiB；读取超时 1.5 秒、完整请求读取期限 4 秒。
- 元数据 HTTP 响应限制为 1 MiB（包括未知长度流）；连接超时 5 秒、读取 8 秒、单次调用 12 秒。使用独立请求取消范围，停止服务不会取消电视播放请求。
- 浏览器 JSON 响应最多 256 KiB。每页本机/账户列表 20 条、搜索/相关作品输出最多 40 条；可操作卡片最多保留 80 条，只存编号、短标题、摘要和最多 2048 字符的 HTTPS 封面地址，不存封面位图或完整详情。超过保留范围的旧卡片要求重新读取。
- 封面由手机浏览器直接懒加载，失败或缺失显示占位；不发送页面 referrer。手机页面不加载外部框架或视频；电视不增加 WebView、图片下载缓存、额外视频缓冲或播放器。授权二维码原始图片最多 128 KiB，通过 data URI 在手机渲染。
- 播放状态每 3 秒读取本地快照；不为轮询调用上游账户接口；页面隐藏后停止轮询。账户列表异步刷新期间每 1.5 秒读取本地加载状态，完成后停止。
- 授权状态仅在账户页可见且授权未结束时每 2.5 秒核对；短信发送冷却至少 60 秒。离开页面或手机切到后台停止轮询，回来后核对结果。
- 会话关闭后关闭全部客户端套接字，停止请求线程、取消元数据请求并释放连接池；过期主线程回调不能改变电视状态。

这些是实现上限，不是 Android 内存实测结果。验收预算仍为：无手机连接时新增 PSS ≤5 MiB，单手机常规操作稳态新增 PSS ≤10 MiB；真机验证后才可判定是否达标。

## 连接边界

每次会话使用随机 192 位地址令牌，只绑定电视选定的局域网 IPv4 地址。请求要求精确 Host，写接口要求同源 Origin 和自定义请求头；拒绝跨站请求、重复请求头和分块上传。网页设置 CSP（仅图片允许 HTTPS 外部资源，API 请求仍限同源）、禁止嵌入、禁止缓存和 referrer，远端标题仅以 textContent 渲染。

账户切换使旧卡片失效，收藏/预约/播放指令携带读取时的账户代次，避免旧页面作用于新账户。手机与电视之间仍是局域网 HTTP，二维码等同本次控制权限，不应分享；应用退出或「断开所有手机」即可撤销。

## 测试与复现

```sh
cd kotlin-tv
./gradlew :core:test :app:testDebugUnitTest :app:lintDebug :app:assembleDebug --console=plain
```

浏览器交互测试需要 Node.js、Playwright 和 Chromium：

```sh
node scripts/test-phone-control-ui.cjs
```

浏览器测试运行本地模拟数据，不连接真实账户、不提交真实收藏或预约。截图写入 `outputs/phone-control-v3/`。服务套接字、鉴权、请求上限、并发上限和关闭由 `PhoneControlServerTest` 验证；API 21/26 上的账户隔离、分页、有限缓存和会话生命周期由 Robolectric 验证。

真机验收建议使用同一视频、同一清晰度和相同预热时间，对比控制台关闭、打开未连接、连接闲置、连续搜索/翻页/切剧、退出重入五组；每组运行至少 10 分钟，重复连接断开 30 次。记录 `adb shell dumpsys meminfo com.hongguotv.nativeapp` 的 TOTAL PSS、Native/Java Heap，结合线程数、GC 和播放掉帧/卡顿比较。特别覆盖 1–2 GB 内存电视、Wi-Fi 断线重连和双手机同时操作。桌面 JVM/Robolectric 数据不能替代电视 PSS 或解码器内存测量。
