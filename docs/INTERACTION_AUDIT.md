# 常用交互复查与简化

日期：2026-11-12。基于手机控制台和一键预约功能分支，未混入多端实验代码。

## 本轮处理

| 流程 | 原交互 | 现在的交互 |
| --- | --- | --- |
| 电视加入账户收藏 | 点击 → 确认 → 写入 → 关闭结果弹窗；未同步时还要刷新 | 点击即提交，短提示反馈；自动核对并最多重试读取一次 |
| 收藏状态暂未同步 | 点击刷新 → 等待 → 再次操作，且刷新可能清掉未确认标记 | 保留原操作意图；重复点击只核对不重复写入，读取未确认时继续保留标记 |
| 取消账户收藏 | 确认后还要关闭结果弹窗 | 保留一次移除确认，结果短提示；手机列表自动更新 |
| 详情页/播放中输入集数 | 输入 → 定位 → 再选中/确认播放 | 输入 →「播放此集」，直接调用现有播放入口；非法集数留在输入面板修正 |
| 账户菜单的云端继续观看 | 没缓存时提示先刷新，用户返回账户菜单重新操作 | 自动读取并直接打开历史列表；失败原地重试；取消或换账户后不弹出过期结果 |
| 手机相关作品 | 进入相关列表后，需要重新搜索/翻页才能返回 |「返回原列表」保留搜索词和页码，并自动重新登记当前页卡片，避免缓存淘汰后无法播放 |
| 手机搜索翻页失败 | 页码先变、内容仍是旧页，用户需要自己退页/重搜 | 失败保留原页码和内容，点击原地「重试」重新请求失败页 |
| 手机收藏/预约后的片单 | 操作完成后仍显示旧列表，需手动刷新 | 状态快照带更新代次，完成后自动读取当前本地片单快照；不额外轮询上游 |
| 手机登录/切换账户 | 账户状态变了，旧片单仍在 | 自动清理旧卡片并读取新账户片单；旧账户操作代次校验继续保留 |

手机端收藏按钮按实际状态显示「加入账户收藏」「取消账户收藏」或「收藏待同步」，避免已经收藏还显示加入、操作中仍能连续点击。浏览器请求增加 25 秒超时反馈，避免页面长期停在无反馈的忙碌状态。

## 已检查并保留的必要步骤

- 删除观看记录、清空搜索记录、恢复备份：保留明确确认，避免误删或合并覆盖。
- 取消账户收藏：保留一次确认；新增收藏无需确认。
- 登录：保留平台扫码确认、验证码和系统交互；不模拟或绕过平台授权。
- 更新安装：已有检查/下载状态复用一个操作按钮；系统安装步骤有实际权限和升级含义，未改为静默安装。
- 倍速、清晰度、画面设置：选择后已直接应用，没有新增确认。
- 播放恢复：已有立即重试、换集等原地动作，不通过关闭页面重进处理。

本次是代码路径复查及自动化验证，不代表所有电视机型和平台接口都已端到端验收。
