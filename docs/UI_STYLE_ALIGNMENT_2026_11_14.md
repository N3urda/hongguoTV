# TV 视觉统一（2026-11-14）

以新版主页和固定侧栏为基准：炭灰背景 #111317、面板 #1D2026、抬升层 #2B2F36、珊瑚强调 #FF705F、正文 #F3F4F6、次级正文 #A4ACB9。系统字体，主标题加粗，遥控器焦点使用明亮轮廓；选中状态使用强调色。

## 调整

- TvVisual 统一引用 TvStyle，移除旧蓝色渐变背景、噪点、橙色光晕。公共弹窗、设置行和分类页签继承同一套中性色与焦点边框。
- 随心看：统一分类和操作卡片，移除视频外层渐变、阴影动画，保留黑色视频区域；标题提高层级，减少底部强调色，修正文案“首页播放”为“随心看”。
- 详情：统一页面背景、封面圆角、选集按钮尺寸；为两行状态增加空间，避免“当前”标签在按钮内裁切。
- 主页面、找剧、搜索、排行榜、我的采用原有侧栏结构；通过公共样式同步使用相同面板、页签、焦点与文本颜色。
